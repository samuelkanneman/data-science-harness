# Incorporar ideas de la comunidad

Conservar las prácticas que aportan valor a ciencia de datos y adaptar sus supuestos al dominio. El volumen de skills instaladas no es un indicador de calidad.

## Registro de una propuesta

Usar el [registro de decisión](../templates/DECISION.md):

- Problema concreto y práctica actual.
- Fuente con URL, versión o commit y fecha de consulta.
- Idea o componente a incorporar y licencia si se reutiliza material.
- Diferencias de datos, permisos, herramientas y entorno.
- Criterio observable para adoptarlo.
- Prueba offline, límites y forma de revertir.
- Estado: propuesta, piloto, adoptada, descartada o pendiente.

Una idea se puede reescribir con atribución. Copiar código o texto sustancial exige respetar la licencia de la fuente. La atribución no sustituye esas condiciones.

## Candidatas iniciales de rsc-harness

| Idea | Estado en este paquete |
|---|---|
| Proceso proporcional: consulta, cambio ordinario y trabajo complejo | Adaptada al método, incluyendo corrida recurrente |
| Tareas completadas mediante evidencia observada | Conservada y explicitada |
| Casos positivos, negativos y pruebas de capacidad para skills | Escenarios iniciales preparados; comportamiento pendiente |
| Revisores independientes y verificación de hallazgos | Incorporada al procedimiento; eficacia pendiente de evaluar |
| Comprobador del harness | Comprobación offline inicial preparada |
| Instalación, permisos Git y sincronización automática | Fuera de la preparación inicial; requieren decisiones y pruebas separadas |

No importar convenciones de desarrollo que contradigan el contrato del análisis, la autorización del usuario o las restricciones de datos.
