1. Ejecutar el verificador y las pruebas desde la raíz del checkout.
2. Leer la documentación exportada y comprobar que corresponde al alcance deseado.
3. Definir cuenta o URL de GitHub y visibilidad. Para un archivo personal en construcción, un repo privado permite decidir más adelante qué distribuir.
4. Elegir licencia si se pretende reutilización pública.
5. Comprobar que el estado Git contiene únicamente los archivos de este paquete.
6. Con autorización para la subida, crear el commit inicial, configurar el remoto y realizar el push.
