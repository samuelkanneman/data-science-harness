## Paquete a revisar

Las skills y las fuentes de adaptación están inventariadas en harness.json. El paquete incluye documentación, plantillas, ejemplos sintéticos y validaciones. No depende de una instalación de rsc. La evidencia observada está en [validación inicial](validacion-inicial.md).

Antes de publicar:

1. Ejecutar el verificador y las pruebas desde la raíz del checkout.
2. Leer la documentación exportada y comprobar que corresponde al alcance deseado.
3. Definir cuenta o URL de GitHub y visibilidad. Para un archivo personal en construcción, un repo privado permite decidir más adelante qué distribuir.
4. Elegir licencia si se pretende reutilización pública.
5. Comprobar que el estado Git contiene únicamente los archivos de este paquete.
6. Con autorización para la subida, crear el commit inicial, configurar el remoto y realizar el push.

## Alcance de esta etapa

La preparación local no crea un repositorio en GitHub, no hace commits y no publica. El futuro clon conservará este paquete; la activación en cada herramienta y las conexiones de datos se prueban por separado.

Un fork de rsc tendría sentido para mantener cambios de su implementación y colaborar con su upstream. La metodología propia tiene estructura, dominio y evolución independientes; se conserva la referencia y la atribución en [procedencia](referencias.md).
